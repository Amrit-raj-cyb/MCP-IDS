API Reference

The fictional Widget API has four endpoints.

  • GET /widgets list widgets
  • GET /widgets/{id} get one widget
  • POST /widgets create a widget
  • DELETE /widgets/{id} remove a widget

All responses are JSON. Rate limit: 60 requests per minute (synthetic).
