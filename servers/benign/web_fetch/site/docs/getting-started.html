Getting Started

1. Install

Download the widget toolkit and unpack it into any folder.

2. Configure

Copy config.example.ini to config.ini and set mode = demo.

3. Run

Start the toolkit and open the dashboard. You should see three sample widgets.

Troubleshooting

If the dashboard is empty, check that demo mode is enabled.
