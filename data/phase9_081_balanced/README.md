# Superseded Phase 9 capture attempt

This directory preserves an interrupted, broad-scenario generation attempt. It is incomplete and is not a verified dataset; do not use it for feature extraction or training. The run was stopped after discovering that most sampling-family scenarios mounted the injector without invoking its probe tool. A targeted, verified replacement is generated separately under `data/phase9_081_targeted/`.

Raw files in this folder have been retained as an audit record. The manifest and logs may not agree because the run was interrupted.
